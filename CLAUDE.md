# CLAUDE.md — MaizExpressN

Working notes for Claude Code. The full spec is in `HANDOFF.md`; read it first.

## Project
An R/Shiny dashboard for looking up maize genes and seeing how their expression changes between nitrogen levels across published RNA-seq studies, with results pooled across studies by tissue, contrast type, growth system and other factors. Owner: Rubén Rellán-Álvarez (GEMMA Lab, NC State).

## Sources of truth
- Studies in scope: `catalogue/maize_N_rnaseq_studies.tsv` (52 core studies). Don't add studies without asking. Dropping studies: the standing rule (Rubén, 18 Oct 2026) and the record of studies not used are in `private/dropped_studies.md` (gitignored; read it before dropping a study). Public files (repo, app) say only "not used in this analysis", never why. Not used so far: Rosman2024, Li2023a, He2016, Ning2023 (`NOT_USED` in build_runs.py, samples `include = FALSE`).
- Curated metadata (once created): `metadata/samples.tsv` and `metadata/contrasts.tsv`.

## Conventions
- Primary gene key: B73 RefGen_v5 gene IDs (`Zm00001eb…`); keep v4/v3 IDs and symbols as searchable aliases.
- Study key: `study_id` from the catalogue.
- Effect sign: log2FC = log2(lower N / higher N), so positive means higher under N limitation. Form contrasts: log2(alternative form / nitrate). The app has a toggle to flip the sign.
- Never pool counts across studies; pool effect sizes (log2FC with SE) only.
- R for analysis and the app (renv). CLI tools in one pinned environment or containers. Heavy processing runs on NC State's Hazel cluster (LSF); only Parquet results come back to the Mac.

- Tissue carry-over, library-QC rule 5 (Rubén, 22 Oct 2026: "I approve rule 5 as drafted (fold 3, +0.5 points, breadth 0.2, unreplicated libraries included)"). `metadata/build/library_exclusions.py` scores root libraries with 81 leaf markers and leaf/shoot libraries with 82 root markers (from the 10 full-length studies with both tissues; whole seedlings not scored). The score is the share of other-tissue mRNA (marker TPM sum / the other tissue's typical sum). A library is excluded when its share is >= 3x its study x tissue median and >= 0.5 points above it, >= 3x its replicates' median (if any), and >= 20% of the markers are >= 3x their study x tissue median.
